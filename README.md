# 모아딜

모아딜은 동네 이웃이 필요한 상품의 수요를 모으고, 판매자와 공동구매 조건을 조율하는 Android 앱입니다. 구매자와 판매자는 이메일로 가입하고 자신의 역할에 맞는 홈에서 거래를 시작할 수 있습니다.

## 공동구매

- **구매자**는 필요한 상품의 공동구매를 요청하거나, 판매자가 등록한 상품을 찾아 참여합니다. 지역과 카테고리로 상품을 좁혀 보고, 관심상품과 거래내역에서 진행 상황을 확인할 수 있습니다.
- **판매자**는 공동구매 상품을 등록하고 참여 현황, 상품 조회수, 구매자 질문을 확인합니다. 모집이 끝난 구매 요청에는 판매 단가, 수량, 픽업 장소를 제안할 수 있습니다.
- **요청자**는 받은 판매 제안을 검토하고 선택할 수 있습니다. 판매자는 픽업 장소를 검색하거나 지도에서 선택해 주소를 확인한 뒤, 거래에 사용할 상세 주소를 직접 입력합니다.

## 동네 커뮤니티

지역과 카테고리로 동네 모임을 찾아 참여하거나 새 모임을 만들 수 있습니다. 참여한 모임에서는 그룹 채팅으로 대화를 나눌 수 있습니다. 구매자와 판매자 모두 출석을 기록할 수 있습니다.
