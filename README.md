# 모아딜

동네 이웃이 구매 수요를 모으고, 판매자가 공동구매 상품과 판매 조건을 제안하는 Java·XML 기반 Android 앱입니다. 현재 예시 구매자·판매자 계정으로 화면과 기능을 체험할 수 있습니다.

## 주요 기능

- 구매자·판매자별 홈과 거래내역, 프로필 수정
- 상품 검색, 전국 지역·카테고리 필터, 관심상품
- 공동구매 요청·판매 상품 등록, 참여 인원과 모집 상태 확인
- 판매 제안 작성·비교·선택, 픽업 장소 선택
- 출석체크, 최저가도전, 랭킹, 마감임박, 한국 날짜별 오늘의 특가
- 상품 질의응답, 판매자 조회수 그래프
- 커뮤니티 모임 생성·검색과 그룹 채팅

## 이용 흐름

- 구매자는 요청을 등록하거나 판매 상품에 참여하고, 모집 현황과 거래내역을 확인합니다. 구매 요청의 모집이 완료되면 판매 제안을 비교하고 요청자가 제안을 선택합니다.
- 판매자는 상품을 등록하고, 참여 인원·조회수·질문을 확인합니다. 판매관리에서 판매진행중과 판매완료 상품을 확인할 수 있습니다.
- 두 계정 모두 커뮤니티 모임과 채팅, 출석체크를 이용할 수 있습니다.

## 이후 개발 계획

- 과제의 사용자 관리 요건에 맞춰 BaaS 기반 실제 회원가입·로그인을 연결하고 계정별 역할을 관리합니다.
- 과제의 외부 연동 요건에 맞춰 픽업 장소 검색 등 외부 API를 1개 이상 연결합니다.
- 현재 로컬 저장 중인 프로필·관심상품·출석에 더해 등록 상품과 거래내역의 저장·복원을 보완합니다.
- 화면 간 데이터 전달과 핵심 거래 흐름을 점검하고, Android Studio의 Java·XML 환경에서 최종 시연을 검증합니다.

현재 회원가입·판매자 심사는 예시 흐름입니다. 거래·질의응답·채팅 데이터는 앱 실행 중 유지됩니다.
